Descent 3MASTERED 0.9.0 Pre-1 - Windows
=========================================

Descent 3MASTERED does not include the commercial Descent 3 game data.

1. Start with a complete Descent 3 installation.
2. Extract this archive into that installation directory, beside d3.hog.
3. Run "Descent 3MASTERED.exe".

The new executable and data archives have distinct names and do not replace the
original Descent 3 executable. OpenAL Soft and the Wooting Analog SDK runtime
are included.

OsirisHost32.exe is launched automatically when a custom mission needs the
experimental legacy 32-bit script bridge. Do not run it manually.

Pilots, saves, screenshots, and downloaded missions are stored under:

  %USERPROFILE%\Saved Games\Descent 3MASTERED
